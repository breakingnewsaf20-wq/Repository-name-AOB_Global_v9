# AOB — د مالک لپاره پاتې کارونه

## ته باید څه وکړې؟
1. د لومړي Demo لپاره وړیا Vercel یا Cloudflare account جوړ کړه.
2. د پروژې نوم `afghan-online-bazaar` وکاروه که available وي.
3. د AOB حقیقي Support Phone او Address وروسته د ⚙️ Owner Settings له لارې ولیکه.
4. Domain وروسته اخیستلای شې؛ د free deployment URL په وسیله پروژه مخکې ښودل کېدای شي.
5. د حقیقي launch لپاره Payment/SMS/AI/Delivery/Email provider accounts جوړېږي.

## زه څه کوم؟
- Frontend/Backend architecture
- Database and API
- Marketplace
- Seller/Admin/Customer systems
- Security hardening
- AI integrations
- Payment/Delivery adapters
- Multilingual UX
- Production deployment configuration
